# AGENTS.md

Classroom activities for primary school, in French: a static Vite + React SPA on Cloudflare Pages, routed by TanStack Router. Tooling is Vite+ (`vp`), on Node 24 (`.node-version`). Before handing work back, run `vp check` and `vp test` and get both green.

## Adding an activity

An activity is a route plus a folder:

- `src/routes/<theme>/<slug>.tsx` declares `staticData.activity` (`theme`, `title`, `description`). The home page and the page title read it from the route tree, so nothing else lists activities. A new theme first gets an entry in `THEMES` (`src/activities/activity.ts`).
- `src/activities/<theme>/<slug>/` holds the activity: a pure `model.ts` with its `model.test.ts`, and the React components, wrapped in `ActivityLayout`.

Keep the route file thin: search params and wiring only.

## Layers

- `src/ui/` is the design system: Tailwind tokens in `theme.css`, generic components. It imports nothing from `activities/`; a component that knows about activities lives there instead.
- `src/lib/` is domain-free helpers (fraction maths, drag, hooks).
- Geometry, snapping and arithmetic live in each `model.ts` as pure functions, so they are tested without a DOM.

## Gotchas

- `src/activities/fractions/grids.ts` builds SVG as strings because `scripts/export.ts` runs it under plain Node to write PNG/SVG files for Google Slides. Keep it free of imports and non-erasable TypeScript.
- `localStorage` keys (`atelier-fractions`, `atelier-zoom`) and the `u`/`d`/`c` search params come from the earlier static site; renaming them loses teachers' saved work and links.
- `src/routeTree.gen.ts` is generated by the router plugin on `vp dev`/`vp build`; commit it, never edit it.
- The repo is public: no secrets, account ids or tokens in it.
